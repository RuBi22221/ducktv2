# ducktv2

ducktv2 es una aplicación especializada en enlaces de televisión que cuenta con su propio formato de archivo `.vx`, similar a `.m3u`. ambos formatos se interpretan a partir de su contenido interno y están orientados al almacenamiento y procesamiento de listas de enlaces de televisión.

https://rubi22221.github.io/ducktv2/

## funciones principales

- **abrir archivos `.vx`:** permite abrir archivos en el formato propio de ducktv2.
- **crear archivos `.vx`:** permite crear nuevos archivos utilizando el formato `.vx`.
- **gestión de enlaces de televisión:** diseñada específicamente para trabajar con enlaces y listas de reproducción televisivas.
- **formato propio:** utiliza `.vx` como extensión personalizada, con un funcionamiento similar al formato `.m3u`.
- **interfaz en español:** todos los botones y elementos de la interfaz están en español.

## cómo utilizar la aplicación

### abrir un archivo `.vx`

1. inicia ducktv2.
2. haz clic en el botón **«abrir .vx»**.
3. selecciona el archivo `.vx` que quieras abrir.
4. la aplicación procesará el archivo según su contenido.

### crear un archivo `.vx`

1. inicia ducktv2.
2. haz clic en el botón **«crear»**.
3. utiliza las opciones disponibles para crear tu archivo `.vx`.
4. guarda el archivo para utilizarlo posteriormente.

## sobre el formato `.vx`

el formato `.vx` es una extensión propia de ducktv2, diseñada para almacenar información relacionada con enlaces de televisión. al igual que `.m3u`, su contenido interno es lo que permite interpretar la información de la lista.

## idioma
